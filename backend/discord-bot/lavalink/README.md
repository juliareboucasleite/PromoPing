# Lavalink local

Arquivos locais para correr o Lavalink do módulo de música.

Comandos:

```powershell
./download-lavalink.ps1
./start-lavalink.ps1
./status-lavalink.ps1
./stop-lavalink.ps1
```

Variáveis usadas:

- `LAVALINK_PORT` (default `2333`)
- `LAVALINK_PASSWORD` (default `promoping-lavalink`)

O `application.yml` já ativa o plugin oficial `youtube-plugin` para pesquisa/playback do YouTube no Lavalink v4.
