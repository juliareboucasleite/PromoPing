# Termos de Serviço - PromoPing

1. O PromoPing é um bot experimental de rastreamento de preços, criado para fins acadêmicos e de prototipagem.
2. O bot não realiza compras, apenas envia notificações de monitoramento de preços.
3. O utilizador é responsável por inserir os links de produtos corretamente.
4. O serviço não garante precisão absoluta dos preços, pois depende do scraping das lojas.
5. O uso é gratuito e não envolve transações financeiras pelo próprio bot.
