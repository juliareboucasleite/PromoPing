# Política de Privacidade - PromoPing

- O PromoPing não coleta informações pessoais sensíveis.
- Apenas são armazenados:
  - Links de produtos que o utilizador deseja monitorar
  - ID do Discord, Telegram ou WhatsApp para envio de notificações
- Os dados são usados exclusivamente para gerar alertas de preços.
- Nenhuma informação é compartilhada com terceiros.
