# PromoPing Bot

O **PromoPing** é um bot de rastreamento de preços integrado ao projeto Rastreador de Preços.  
Ele permite que utilizadores recebam **notificações de promoções** diretamente em **Discord, Telegram ou WhatsApp**.

## Funcionalidades
- Monitoramento de produtos ligado ao dashboard web
- Notificações automáticas quando houver alteração de preços
- Histórico de preços acessível pelo frontend
- Suporte a múltiplos canais de envio

## Tecnologias
- Discord.js
- Telegraf (Telegram)
- Twilio (WhatsApp)
- Node.js + Express (backend)
- Puppeteer (scraping de preços)

## Status
Atualmente em fase de desenvolvimento. O bot já conecta às plataformas e aguarda integração total com o sistema de scraping.
