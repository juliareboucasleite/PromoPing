Visão Geral

A API PromoPing permite integrar o monitoramento de preços na sua aplicação. Todos os endpoints requerem autenticação através de token JWT.

Limitação de Taxa

A API implementa limitação de taxa por plano:

  • Free: 100 pedidos/hora
  • Basic: 500 pedidos/hora
  • Standard: 1000 pedidos/hora
  • Premium: 2000 pedidos/hora

Funcionalidades Principais

A API PromoPing oferece endpoints para gestão completa do monitoramento de preços:

Autenticação

Registo, login e OAuth

Utilizadores

Perfil, estatísticas e gestão

Produtos

Gestão completa de produtos e preços

Notificações

Alertas e preferências

Pagamentos

Checkout e gestão de assinaturas

Exportação

Relatórios em Excel e PDF
