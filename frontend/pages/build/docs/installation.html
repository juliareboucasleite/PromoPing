Guia de Instalação

PromoPing é um Serviço Web

O PromoPing é um serviço web completo de monitoramento de preços. Não é necessário instalar ou configurar nada no seu computador.

Basta criar uma conta e começar a usar diretamente no navegador. Tudo funciona na nuvem!

Como Começar

Para começar a usar o PromoPing:

  1. Crie uma conta no nosso site
  2. Adicione produtos para monitorizar
  3. Configure os seus alertas de preço
  4. Receba notificações quando os preços mudarem
Dica: Se desejar receber notificações através do Discord, pode adicionar o nosso bot aos seus servidores Discord. Veja mais no guia de utilização.
