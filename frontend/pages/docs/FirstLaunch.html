Getting Started

Welcome to PromoPing!

This guide will help you set up PromoPing for the first time and get you monitoring your favorite products in minutes.

System Requirements

Before starting, ensure your system meets these requirements:

  • Node.js 16.0 or higher
  • MySQL 8.0 or higher
  • At least 2GB of available RAM
  • Stable internet connection

Installation Steps

1. Clone the Repository

git clone https://github.com/yourusername/PromoPing-2.0.1.git

2. Install Dependencies

cd PromoPing-2.0.1
npm install

3. Environment Configuration

Create a .env file in the root directory:

# Database Configuration
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=promoping

# API Keys
STRIPE_SECRET_KEY=your_stripe_key
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Server Configuration
PORT=3000
NODE_ENV=development

4. Database Setup

Run the database migrations:

npm run migrate

5. Start the Application

npm start

First Time Setup

Once the application is running:

  1. Open your browser and navigate to http://localhost:3000
  2. Create your first admin account
  3. Configure your notification preferences
  4. Add your first product to monitor

Troubleshooting

If you encounter any issues during setup:

  • Check that all environment variables are correctly set
  • Ensure MySQL is running and accessible
  • Verify that all required ports are available
  • Check the console logs for specific error messages
