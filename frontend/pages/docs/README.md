# PromoPing Documentation

Esta é a documentação oficial do PromoPing, uma plataforma de monitoramento de preços de produtos.

## Estrutura da Documentação

### Páginas Disponíveis

- **docs.html** - Página principal com visão geral do PromoPing
- **FirstLaunch.html** - Guia de primeira instalação e configuração
- **usage-guide.html** - Guia completo de uso da plataforma
- **api-reference.html** - Documentação completa da API

### Arquivos de Suporte

- **styles.css** - Estilos CSS para toda a documentação
- **script.js** - Funcionalidades JavaScript (busca, navegação, feedback)
- **README.md** - Este arquivo

## Características da Documentação

### Design
- Interface escura moderna
- Navegação lateral intuitiva
- Busca integrada (Ctrl+K)
- Sistema de feedback com emojis
- Design responsivo

### Funcionalidades
- Navegação suave entre páginas
- Botão de cópia de conteúdo
- Sistema de feedback interativo
- Atalhos de teclado
- Scroll automático para o topo

### Estilos
- Tema escuro consistente
- Código destacado com syntax highlighting
- Alertas coloridos para diferentes tipos de informação
- Badges para métodos HTTP
- Tabelas estilizadas
- Listas organizadas

## Como Usar

1. Abra `docs.html` no navegador
2. Navegue pelas seções usando o menu lateral
3. Use Ctrl+K para buscar conteúdo
4. Clique nos botões de feedback para avaliar a documentação
5. Use o botão "Copy" para copiar o conteúdo da página

## Personalização

Para personalizar a documentação:

1. **Cores**: Edite as variáveis CSS no arquivo `styles.css`
2. **Conteúdo**: Modifique os arquivos HTML correspondentes
3. **Funcionalidades**: Adicione JavaScript no arquivo `script.js`
