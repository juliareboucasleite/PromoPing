Como podemos ajudar?

Nossa equipe de suporte está aqui para ajudar você a aproveitar ao máximo o PromoPing. Encontre respostas rápidas para suas perguntas ou entre em contato conosco.

Perguntas Frequentes (FAQ)

🔧 Configuração e Instalação

Como instalar o PromoPing pela primeira vez?

Siga nosso guia completo de primeira instalação que inclui todos os passos necessários.

Quais são os requisitos mínimos do sistema?
  • Node.js 16.0 ou superior
  • MySQL 8.0 ou superior
  • 2GB de RAM disponível
  • Conexão estável com a internet
Como configurar as variáveis de ambiente?

Crie um arquivo .env na raiz do projeto com as configurações necessárias. Veja exemplos na documentação de instalação.

Uso e Funcionalidades

Como adicionar produtos para monitoramento?

Você pode adicionar produtos de duas formas: colando a URL diretamente ou inserindo as informações manualmente. Veja detalhes no guia de uso.

Quais tipos de alertas estão disponíveis?
  • Queda de preço: Notifica quando o preço cai abaixo do limite
  • Aumento de preço: Alerta sobre aumentos significativos
  • Disponibilidade: Notifica quando produtos voltam ao estoque
  • Resumo diário: Recebe atualizações diárias de preços
Como configurar notificações por WhatsApp?

Configure sua conta WhatsApp nas preferências de notificação. Você receberá um código de verificação para ativar as notificações.

API e Integração

Como obter uma chave de API?

As chaves de API são geradas automaticamente quando você cria uma conta. Acesse seu perfil para visualizar e gerenciar suas chaves.

Existe limite de requisições na API?
  • Plano gratuito: 100 requisições por hora
  • Plano premium: 1000 requisições por hora
  • Enterprise: Limites personalizados
Como integrar com Discord?

Configure o bot do Discord nas suas preferências. Veja a documentação da API para detalhes técnicos.

Pagamentos e Planos

Quais métodos de pagamento são aceitos?

Aceitamos cartões de crédito, débito e PayPal através do Stripe.

Posso cancelar minha assinatura a qualquer momento?

Sim, você pode cancelar sua assinatura a qualquer momento através do seu painel de controle. O acesso permanece ativo até o final do período pago.

Há período de teste gratuito?

Oferecemos 14 dias de teste gratuito para todos os novos usuários. Não é necessário cartão de crédito para começar.
